# E-Commerce Full-Stack App

### 👋 Hello guys,

This is a E-Commerce application built to lean the full stack application with

- [Next.js][nextjs] (Web frontend)
- [Nest.js][nestjs] (Backend)
- [React Native][reactnative] (Mobile frontend)
- [PostgreSQL][postgresql] (Database)

---

At first to create full stack app need to choose the application frameworks.  
For this project we are using Next.js, NestJS, React Native, PostgreSQL.

Lets get started by creating this README.md file inside root of this project for documentation.

## Monorepo Architecture

To create and manage multiple JS applications in one repository efficiently we are using a tool called [TurboRepo][turborepo].

Setup monorepo with Turborepo click [here](turborepo.md).
